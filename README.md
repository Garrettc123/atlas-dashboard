# ATLAS Dashboard 📊

> **Next.js 14 Admin Panel**  
> Lead pipeline · Agent status · Revenue analytics  
> Garcar Enterprise — ATLAS Platform

[![Deploy](https://github.com/Garrettc123/atlas-dashboard/actions/workflows/deploy.yml/badge.svg)](https://github.com/Garrettc123/atlas-dashboard/actions/workflows/deploy.yml)
[![Next.js](https://img.shields.io/badge/Next.js-14-black)](https://nextjs.org)

## Features

- ⚡️ Real-time lead pipeline visualization
- 🤖 7-agent status monitoring with health indicators
- 💰 Revenue dashboard (MRR, ARR, conversion rates)
- 📊 Lead scoring distribution charts
- ✅ Compliance metrics (opt-out rates, send window blocks)
- 🌐 Multi-tenant (manage all contractor clients)

## Deploy to Vercel

```bash
npx vercel --prod
```

Or push to `main` for automatic Vercel deployment via GitHub Actions.

## Local Development

```bash
npm install
npm run dev
# Open http://localhost:3000
```
